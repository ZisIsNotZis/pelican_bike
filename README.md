# Pelican Express

> **Status: closed (milestone, 2026-09-29).** A finished single-page visual demo.
> No further development is planned unless the project's inputs or goals change.

An interactive single-page cycling demo that visualizes a Pelican bike ride across changing speed modes. Open [`pelican_bike.html`](pelican_bike.html) in a modern browser to explore the presentation; the adjacent preview images and ride video are showcase artifacts from the project.

[`record3.js`](record3.js) contains the recording helper used to produce the ride capture. The page is a visual demo rather than a calibrated physics or training tool.
